
# 🎓 Placement Prediction System

An end-to-end Machine Learning web application that analyzes student academic, technical, experience, and profile information to generate an estimated placement prediction.

The system supports both **manual student assessment** and **resume-based assessment**, with a FastAPI backend and an interactive HTML/CSS/JavaScript frontend.

---

## 📌 Project Overview

The Placement Prediction System is designed to estimate whether a student is likely to be placed based on multiple academic, technical, professional, and extracurricular attributes.

The system provides:

- Manual student assessment
- Resume upload and analysis
- Placement prediction
- Placement probability
- Personalized recommendations
- Prediction history
- Dashboard statistics
- Multiple ML model comparison
- Feature importance analysis
- FastAPI REST API
- Interactive web frontend

> **Important:** The prediction generated by this system is an estimate based on the trained machine learning model. It is not a guarantee of actual placement.

⚠️ Limitations

The current model has moderate predictive performance:

Accuracy: 57.06%
ROC-AUC: 58.46%

Therefore, predictions should be interpreted as model-based estimates, not guaranteed placement outcomes.

The quality of predictions depends strongly on:

Dataset quality
Feature quality
Dataset provenance
Representation of students
Target definition
Training data

The current project should not be used as the sole basis for real-world employment decisions.
